# Marketing-Funnel-Analysis-using-SQL-PowerBI-and-Excel
Marketing Funnel Analysis evaluates how visitors move through key conversion stages and identifies where the largest drop-offs occur.
•	Analyzed customer movement in different stages of marketing funnel to identify conversion and drop-off points.
•	Used SQL and Excel to calculate funnel metrics, conversion rates, and stage-wise customer performance.
•	Built an interactive Power BI dashboard to visualize the funnel, customer conversion trends, and key performance indicators.

Tools
- Excel
- MySQL / SQL
- Power BI
